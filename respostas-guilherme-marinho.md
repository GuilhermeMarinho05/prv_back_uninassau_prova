1.Qual a diferença entre git init e git clone?
	O git clone clona uma repositório já pronto e o git init cria um do zero.

2.O que faz o comando git status?
	Serve para mostrar a situação atual do seu código e as modificações feitas.

3.Para que serve o git add antes do git commit?
	Serve para colocar os arquivos adicionados em preparação para fazer um commit.

4.Qual a diferença entre git pull e git fetch?
	O git fetch baixa e já faz merge no seu arquivo e o git pull apenas baixa.

5.O que é um branch e por que ele é usado?
	É basicamente um espelho do projeto, servindo para não trabalhar diretamente código original.
 
6.O que é um Pull Request no GitHub?
	É um pedido para enviar seu arquivo para o arquivo principal.

7.Explique a diferença entre branch de origem e branch de destino em um PR.
	Branch de origem é onde se faz a alteração e a branch de destino é para onde vai a alteração.

8.O que acontece se duas pessoas alterarem a mesma linha de um arquivo em branches diferentes?
	O git não consegue identificar qual o código certo, precisando de um programador para decidir qual código escolher.

9.Para que serve o arquivo .gitignore?
	Serve para ignorar completamente certos tipos de arquivos.

10.Qual é a função do README.md em um projeto?
	O readme é o se coloca as instruções do projeto
